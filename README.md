# Aurea
Visual Laboratory 
**AUREA – Liquid Forms**

Eine interaktive WebGL-App, die Formen, Bilder und Musik zu animierten Lichtwelten verbindet.

* Verschiedene Figuren und Formen, darunter Wellen, LUNC-Logo und Grok-Bot.
* Eigene Bilder als Partikel, Konturen oder Relief visualisieren.
* Musik laden und Animationen auf Bass, Rhythmus und Höhen reagieren lassen.
* Farben, Bewegung, Kamera und Bot-Emotionen anpassen.
* Bilder als PNG, Videos als MP4 oder WebM und Projekte als JSON speichern.
* Deutsche und englische Oberfläche.

**Video exportieren:** Studio → Export → Format wählen → aufnehmen → speichern. Während der Aufnahme im Tab bleiben. MP4 ist abhängig von der Unterstützung deines Browsers und Geräts.

**Projekte:** JSON-Dateien lassen sich wieder in AUREA öffnen. Musikdateien müssen anschließend erneut ausgewählt werden. Hochgeladene Bilder und Musik werden lokal im Browser verarbeitet.
